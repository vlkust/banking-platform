# Bank System Project

A modular banking system written in Python using object-oriented design principles.

## Project Structure

```text
bank-system/
├── README.md
├── requirements.txt
├── src/
│   ├── main.py
│   ├── models.py
│   ├── utils.py
│   ├── exceptions.py
├── tests/
```

## Run

```bash
cd src
python main.py
```
